# Эстетик Дент — прототип сайта

[Открыть прототип](https://ipenyashkin.github.io/estetik-dent/) · [Редактор данных клиники](https://ipenyashkin.github.io/estetik-dent/studio.html)

Адаптивный демонстрационный сайт стоматологии: главная, восемь страниц услуг, фильтр направлений, FAQ, контакты и сценарий записи. HTML, CSS и JavaScript без сборки. Фотографии и шрифты размещены локально.

Это предложение нового дизайна, а не официальный сайт клиники. Форма демонстрационная: данные не отправляются и не сохраняются. Фотографии иллюстративные. Индексация отключена.

## Запуск локально

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173/.

## Адаптация

Все заменяемые данные находятся в `clinic.config.js`: название, контакты, часы работы, цвета, фотографии, услуги и FAQ. На странице `studio.html` можно поменять данные и скачать новый файл конфигурации. Настройки редактора сохраняются только в вашем браузере и не меняют сайт для других посетителей. Для публикации замените `clinic.config.js` в репозитории; GitHub Pages публикует корень ветки `main`.

Перед рабочим запуском клиника предоставляет актуальные цены, сведения о врачах, фотографии, документы и согласованные тексты обработки персональных данных; форма подключается к выбранной системе записи.
